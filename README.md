# Max Level Code — releases

Windows installers for [Max Level Code](https://maxlevelcode.com), a desktop code editor with a built-in AI coding agent. Each release has a setup program (`.exe`) and an MSI; download the latest from the **Releases** page on the right.

Max Level Code is free to use under the terms of use that ship with the app (Help > About). It is built on [Cline](https://github.com/cline/cline) (Apache 2.0); the licences and notices are installed with the application.

The installer is not code-signed, so Windows SmartScreen may warn: choose "More info", then "Run anyway". Installing over an existing version keeps your settings. Use at your own risk.
